# 📊 FinGuard Analytics — Dashboard de Riesgo Financiero

Dashboard ejecutivo de análisis de riesgo crediticio y modelo 
predictivo desarrollado en Power BI con datos generados en Python.

## 🚀 Características

- Segmentación de clientes por nivel de riesgo (Low, Medium, High)
- Modelo predictivo de probabilidad de default
- Detección de alertas de fraude
- Análisis de portafolio de préstamos
- KPIs ejecutivos en tiempo real
- Análisis de volumen mensual de transacciones

## 📈 Métricas del Dashboard

- **5 millones** de clientes activos analizados
- **2 millones** de clientes en riesgo identificados
- **2 millones** de alertas de fraude procesadas
- **$149.88 millones** en volumen total de transacciones
- **25.46%** riesgo promedio del portafolio

## 🛠️ Tecnologías

- Power BI (visualización y modelado)
- Python (generación de datos sintéticos)
- DAX (métricas y cálculos)
- SQL Server (fuente de datos)
